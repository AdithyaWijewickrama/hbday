# Happy Birthday, Ishani 🎂

A little birthday surprise website: a gift box intro, a trick quiz, a cake she cuts herself,
a photo gallery, flip cards, a typed-out note, and a tiny party buddy who follows her around.

Plain HTML, CSS and JavaScript. No build step.

- `index.html` – the page
- `css/style.css` – page styles, `css/buddy.css` – the little buddy
- `js/main.js` – quiz, cake, gallery, letter (edit the `CONFIG` block at the top to change text)
- `js/buddy.js` – the buddy (moves, sits on things, reacts), `js/sound.js` – tiny synthesized sounds
- `photos/` – pictures

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
Repository Settings → Pages → Deploy from branch → `main` / root.
